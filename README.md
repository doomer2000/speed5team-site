# 💻 speed5team-site — Company Landing Page

**speed5team-site** is a clean, modern company landing page built with **HTML, CSS, and JavaScript**.  
It was developed as a **showcase website** for my previous workplace, featuring a simple design and an integrated **chatbot** for user interaction.

---

## 🚀 Features
- 🖥 Fully **responsive design** for desktop, tablet, and mobile devices.  
- 💬 Integrated **chatbot** to answer basic user questions.  
- 🌐 Clean, semantic **HTML5** and structured **CSS3**.  
- ⚡ Minimalist, fast-loading **JavaScript** interactions.  
- 🧩 Modular structure for easy updates and maintenance.

---

## 🧱 Architecture
- **index.html** — main landing page.  
- **CSS folder** — stylesheets for layout and responsiveness.  
- **JS folder** — client-side scripts, including chatbot logic.  
- **Assets** — images, icons, and media files.
